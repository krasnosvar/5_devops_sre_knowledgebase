# Раздел 12. Подготовка к собеседованию

Сборник вопросов и развёрнутых ответов для собеседований на позиции
DevOps/SRE, разложенный по тем же доменам, что и основная база: Linux,
сети, контейнеры, CI/CD, IaC, мониторинг, базы данных, облака, DevSecOps,
MLOps, языки и system design. Это не учебник с нуля, а инструмент
повторения: вопрос → проверить себя → свериться с ответом → при пробеле
вернуться в соответствующий раздел базы.

## Формат файлов `.sh` — это намеренно

Файлы с вопросами имеют расширение `.sh`, хотя это не исполняемые скрипты.
Это осознанное решение автора, а не ошибка: так файлы удобно открывать в
терминале (`less`, `vim`) с подсветкой комментариев, а внутри сохраняется
единый формат:

- `# N. Вопрос` — заголовок вопроса (строка начинается с `# ` и номера);
- следом — ответ обычным текстом, перенос строк на 70-80 символов;
- `**Доп. вопрос: ...?**` — уточняющий вопрос внутри того же номера.

Не конвертируйте эти файлы в `.md` и не запускайте их через `bash`.

## Пререквизиты

- Пройденные разделы базы по тем доменам, к которым готовитесь: например,
  перед `03_containers_and_orchestration/` — [3_containers](../3_containers/)
  и [4_kubernetes](../4_kubernetes/). Вопросы опираются на терминологию
  этих разделов и не объясняют её заново.

## Как пользоваться

1. Прочитать [interview_guide.md](./00_theory/interview_guide.md), чтобы
   понимать структуру интервью.
2. Открыть файл по нужному домену и отвечать на вопрос вслух или
   письменно, не глядя в ответ (например, `less 01_linux/01_processes.sh`
   и листать по заголовкам `# N.`).
3. Сверить свой ответ с написанным; где ответ не сошёлся — вернуться в
   теорию соответствующего раздела базы.
4. Повторять файлы через несколько дней, отмечая вопросы, на которых
   «плавали».

  файла по вашим доменам.
- Можете объяснить «подвох» в продвинутых вопросах, а не только
  пересказать определение.
