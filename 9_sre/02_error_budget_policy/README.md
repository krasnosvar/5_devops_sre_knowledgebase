# 02. Error Budget Policy

> Уже знакомы с темой? → [CHEATSHEET.md](./CHEATSHEET.md) — команды и шаблоны одним экраном.

## Зачем
Error budget сам по себе — просто число. Политика отвечает на вопрос
«что команда делает, когда бюджет кончился»: замораживает фичи,
переключается на надёжность, кто принимает решение. Без заранее
согласованной политики каждый инцидент заканчивается спором
разработки и эксплуатации.

1. Прочитать теорию.
2. Заполнить шаблон `error-budget-policy.md` для знакомого сервиса:
   пороги бюджета, действия, ответственные.

## Когда двигаться дальше
- Можете объяснить, какие действия наступают при 50%, 25% и 0%
  оставшегося бюджета и почему.
- Можете аргументировать политику перед продуктовой командой без
  слов «надёжность важнее фич».
