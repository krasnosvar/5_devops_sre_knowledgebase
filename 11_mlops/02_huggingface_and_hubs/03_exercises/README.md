# Упражнения — Экосистема Hugging Face и форматы моделей

Стенд: 🐳 Tier 1 — Локальный Python / Docker (CPU-only, без NVIDIA GPU).

## Упражнение 1 — Разбор бинарного заголовка `.safetensors` без загрузки весов

**Задача:**
1. Запустить скрипт `../02_examples/inspect_safetensors_and_onnx.py` и
   убедиться, что при десериализации `pickle` метод `__reduce__`
   выполняется автоматически.
2. Написать однострочник или короткий скрипт на Python, который открывает
   сгенерированный файл `.safetensors`, читает только первые 8 байт
   (`uint64` little-endian) и JSON-заголовок, и выводит суммарный объём
   тензоров в байтах по полю `data_offsets`, не читая сам массив весов.

## Упражнение 2 — Детерминированное скачивание с Hugging Face и офлайн-режим

**Задача:**
1. Настроить переменную `HF_HOME=$HOME/.cache/mlops-models/hf`.
2. Скачать конфигурационные файлы легковесного русского/мультиязычного
   эмбеддера `intfloat/multilingual-e5-small` (только `config.json` и
   `tokenizer_config.json`, без гигабайтного файла весов), жёстко указав
   ветку/ревизию.
3. Проверить структуру папок `blobs/` и `snapshots/` внутри `$HF_HOME/hub/`.
4. Включить `export HF_HUB_OFFLINE=1` и убедиться, что повторное обращение
   к файлу из кэша работает при полностью отключённой сети.

## Упражнение 3 — Сборка кастомного `Modelfile` с фиксацией потоков CPU

**Задача:**
1. Изучить файл `../02_examples/Modelfile.doc-assistant`.
2. Проверить топологию своего процессора через `lscpu -e=CPU,CORE,MAXMHZ` и
   определить точное число физических P-ядер.
3. Собрать в контейнере `Ollama` образ `doc-assistant` на базе компактной
   модели `qwen2.5:0.5b` (или `qwen2.5:7b-instruct-q4_K_M`) с параметром
   `PARAMETER num_thread <число_P_ядер>` и протестировать извлечение
   категории документа из строки текста медицинского анализа.
