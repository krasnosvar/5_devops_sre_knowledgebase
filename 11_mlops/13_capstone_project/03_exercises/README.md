# Упражнения: Сквозной проект — Личная база документов

Стенд: 🐳 Tier 1 (чистый Python 3 на хосте, опционально Docker / `k3d`).

## Упражнение 1 — Сквозной самотест пайплайна (`--self-test`)

Запустите `./02_examples/personal_vault_app.py --self-test` и убедитесь,
что все 4 этапа (SQLite реестр, связка Модели №1 и Модели №2, защита от
Prompt Injection и выгрузка таблицы в CSV для Excel) проходят успешно.

## Упражнение 2 — Запрос к базе документов из CLI и проверка Excel-выгрузки

1. Задайте вопрос через `--query` о том, когда будет готов загранпаспорт
   по расписке из МФЦ.
2. Проверьте первые 3 строки сгенерированного файла
   `/tmp/personal_docs_vault_export.csv` и наличие 3-байтового маркера
   `UTF-8 BOM` (`ef bb bf`), чтобы убедиться, что файл откроется в
   Excel без искажения кириллицы.
