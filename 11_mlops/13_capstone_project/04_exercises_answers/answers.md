## Упражнение 2 — Запрос к базе документов из CLI и проверка Excel-выгрузки

Команда:
```bash
./11_mlops/13_capstone_project/02_examples/personal_vault_app.py \
  --query "Когда будет готов загранпаспорт по расписке из МФЦ?"
head -c 3 /tmp/personal_docs_vault_export.csv | od -An -tx1
head -n 3 /tmp/personal_docs_vault_export.csv
```

Ожидаемый вывод (приблизительно):
```text
{
  "question": "Когда будет готов загранпаспорт по расписке из МФЦ?",
  "routed_category": "gov",
  "router_confidence": 0.999,
  "answer": "По данным документа [gov_002] от 2026-02-03 (МФЦ Мои Документы): ...",
  "sources": [
    {
      "doc_id": "gov_002",
      "doc_date": "2026-02-03",
      "source": "МФЦ Мои Документы",
      "file_uri": "~/personal_docs_vault/2026/gov/gov_002.pdf"
    }
  ]
}
 ef bb bf
ID документа;Дата;Категория (ML Router);Уверенность роутера;...
```

**Почему так:** первые три байта `ef bb bf` (`utf-8-sig`) сообщают
Excel, что файл в кодировке UTF-8, а разделитель `;` соответствует
русской локали табличных редакторов.
