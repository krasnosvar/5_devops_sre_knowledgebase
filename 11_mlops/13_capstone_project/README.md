# 13. Сквозной проект (Capstone): Личная база документов (MLOps + LLMOps)

> Уже знакомы с темой? → [CHEATSHEET.md](./CHEATSHEET.md) — шпаргалка
> по архитектуре «Личной базы документов», гибридному хранению (Файлы +
> SQLite/Postgres + выгрузка в Excel + Qdrant) и запуску в Docker / `k3d`.

## Зачем

Этот проект объединяет **все 12 предыдущих разделов курса** (классический
MLOps и современный LLMOps) в одну практическую систему, которой вы
будете пользоваться в реальной жизни: **Персональное хранилище и
ИИ-ассистент по вашим документам** (анализы и заключения врачей,
налоговые уведомления ФНС и выписки МФЦ/Госуслуг, чеки/полисы ОСАГО/
гарантии и личные технические заметки).

Почему мы выбрали **Веб-сервис + БД метаданных с выгрузкой в Excel в
1 клик**, а не просто таблицу Excel:
- в ячейке Excel невозможно удобно хранить и искать многостраничные
  PDF-сканы, фото чеков и медицинские бланки;
- наш сервис хранит оригиналы файлов (фото, PDF, видео) в структурированной
  папке (`~/personal_docs_vault/` или S3 `SeaweedFS`), автоматически
  распознает текст, классифицирует категорию **Моделью №1 (Классический
  ML / ONNX)**, индексирует чанки для умного поиска **Моделью №2 (Hybrid
  RAG + локальная LLM)** и в любой момент выгружает вам готовую
  **таблицу для Excel** с кликабельными ссылками на файлы и суммами!

## Пререквизиты

- Все разделы `00`–`12` модуля `11_mlops`.
- Приватная папка для ваших реальных документов создается **вне** Git-репозитория
  (`~/personal_docs_vault/`), а внутри репозитория тесты работают на
  синтетическом архиве вымышленного «Иванова И.И.».

## Файлы

- [CHEATSHEET.md](./CHEATSHEET.md) — шпаргалка по командам и архитектуре
  проекта.
- `01_theory/`
  - [capstone_architecture.md](./01_theory/capstone_architecture.md) —
    полная архитектура, схема хранения, связка Модели №1 (Роутер) и
    Модели №2 (RAG), мониторинг дрейфа, безопасность ПДн и 10 Q&A.
- `02_examples/`
  - [personal_vault_app.py](./02_examples/personal_vault_app.py) —
    полностью рабочий сервис Личной базы документов (работает сразу на
    чистом Python 3 хоста):
    - `--self-test` — полный сквозной прогон пайплайна (валидация данных
      $\rightarrow$ обучение роутера $\rightarrow$ PII-сканер $\rightarrow$
      гибридный RAG-поиск $\rightarrow$ экспорт реестра в таблицу Excel);
    - `--query "..."` — поиск ответа по вашим документам из CLI;
    - `--export-csv /tmp/my_docs.csv` — выгрузка реестра документов с
      колонками для Excel (с поддержкой UTF-8 BOM для корректного
      открытия русских букв в Excel);
    - `--serve` — запуск локального Веб-интерфейса (`http://127.0.0.1:8090`)
      с таблицей документов, кнопкой скачивания Excel/CSV и окном ИИ-ассистента.
  - [docker-compose.yml](./02_examples/docker-compose.yml) — полный стек
    с `Qdrant`, `Ollama` (6 P-ядер Intel 155H), `MLflow` и `Prometheus`.
  - [k8s-manifests.yaml](./02_examples/k8s-manifests.yaml) — манифесты
    для деплоя в локальный кластер `k3d` с `initContainer` и `startupProbe`.
- `03_exercises/`
  - [README.md](./03_exercises/README.md) — пошаговые задания по сборке
    и проверке проекта.
- `04_exercises_answers/`
  - [answers.md](./04_exercises_answers/answers.md) — разбор решений.

## Как проходить

1. Изучите архитектуру в [01_theory/capstone_architecture.md](./01_theory/capstone_architecture.md).
2. Запустите `./02_examples/personal_vault_app.py --self-test` и
   выполните упражнения из [03_exercises/README.md](./03_exercises/README.md).
3. Подключите свою локальную папку `~/personal_docs_vault/` (не коммитя
   её в Git!) и протестируйте веб-интерфейс `--serve`.
