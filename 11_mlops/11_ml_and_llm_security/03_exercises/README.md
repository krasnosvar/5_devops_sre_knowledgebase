## Упражнение 1 — Сканирование ПДн, Prompt Injection и Pickle-файлов

Запустите сканер `./02_examples/pii_and_security_scanner.py` и разберите

## Упражнение 2 — Дизассемблирование Pickle через `pickletools`

С помощью встроенного модуля `python3 -m pickletools` выведите полный
дизассемблированный листинг опкодов стековой машины для безопасного
словаря `{"a": 1}` и объясните, почему в нем нет опкода `REDUCE`.
