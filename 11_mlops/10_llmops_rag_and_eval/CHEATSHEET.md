## Выбор способа адаптации LLM

| Подход | Когда выбирать | Стоимость и сложность |
| :--- | :--- | :--- |
| **Prompt Engineering** | Изменить тон, формат вывода (JSON), добавить 3–5 few-shot примеров | Минимальная (без переобучения и БД) |
| **RAG (Retrieval-Augmented Generation)** | Приватные документы, часто меняющиеся факты, обязательные ссылки на источник | Средняя (нужен эмбеддер + `Qdrant`) |
| **Fine-Tuning (LoRA / QLoRA)** | Узкоспециальный синтаксис, сжатие промпта, обучение малой модели (`0.5B–3B`) конкретному навыку | Высокая (нужен датасет SFT и пайплайн) |

## Двухэтапный Hybrid RAG для Личной базы документов

```text
Вопрос ──► [1. Classical ONNX Router] (отсекает offtopic, ставит фильтр category)
                 │
                 ▼
       [2. Qdrant Hybrid Search: Dense (bge-m3) + Sparse (BM25) + RRF] ──► top-20
                 │
                 ▼
       [3. Cross-Encoder Reranker (bge-reranker, ONNX INT8)] ──► top-4 чанка
                 │
                 ▼
       [4. Local LLM (Qwen2.5/Qwen3 в Ollama) + Строгий промпт со ссылками]
```

## Метрики оценки RAG (Retrieval vs Generation)

| Контур | Метрика | Что измеряет |
| :--- | :--- | :--- |
| **Retrieval (без LLM)** | **Hit Rate @ k (Recall@k)** | Доля вопросов, где правильный документ попал в `top-k` выдачи |
| **Retrieval (без LLM)** | **MRR (Mean Reciprocal Rank)** | Среднее от $1/\text{rank}$ первого релевантного документа (учитывает позицию) |
| **Generation (RAGAS)** | **Faithfulness (Groundedness)** | Не выдумала ли LLM факты, которых **нет** в переданных чанках контекста |
| **Generation (RAGAS)** | **Answer Relevancy** | Отвечает ли сгенерированный текст именно на заданный вопрос |

## Частые ловушки

| Симптом | Причина | Решение |
| :--- | :--- | :--- |
| Векторный поиск не находит справку по точному номеру `77:01:0001012:4589` | Dense-эмбеддинги сглаживают точные цифры и аббревиатуры | Включить **Hybrid Search** (`Dense + Sparse BM25`) с слиянием рангов **RRF** |
| При замене модели эмбеддингов поиск начал выдавать случайный мусор | Векторные пространства разных моделей несовместимы | Переиндексировать всю коллекцию в новую коллекцию `docs_v2` и переключить алиас в Qdrant |

> Проверка: структура и ссылки проверены.
