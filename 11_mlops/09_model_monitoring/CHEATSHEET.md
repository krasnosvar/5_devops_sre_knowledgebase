# Мониторинг моделей и Data Drift — шпаргалка

Теория: [model_monitoring.md](./01_theory/model_monitoring.md).
`⚠️` = опасная команда / частая ловушка.

## Типы дрейфа в ML

| Тип дрейфа | Математическое определение | Пример в Личной базе документов |
| :--- | :--- | :--- |
| **Data / Covariate Shift** | Меняется $P(X)$, но $P(Y \mid X)$ неизменно | Появились фото документов с телефона с плохим OCR вместо чистых PDF |
| **Prior / Label Shift** | Меняется $P(Y)$ (распределение классов) | В апреле (налоговый период) 80% загружаемых документов — справки ФНС |
| **Concept Drift** | Меняется сама зависимость $P(Y \mid X)$ | Изменилось законодательство или форма выписки: старые признаки значат другое |

## Выбор статистического теста для детекции дрейфа

| Тип признака и размер окна | Критерий / Метрика | Пороги принятия решений |
| :--- | :--- | :--- |
| Любой числовой / вероятности (большие выборки) | **PSI** (Population Stability Index) | `< 0.10` — норма; `0.10–0.25` — внимание; `⚠️ > 0.25` — сильный дрейф |
| Непрерывный признак (выборка `100..2000` строк) | **KS-test** (Колмогорова-Смирнова) | `p-value < 0.05` (при больших $N > 10\,000$ дает ложные срабатывания!) |
| Категориальный признак | **Chi-squared ($\chi^2$)** или **Jensen-Shannon** | `JS > 0.1` или `p-value < 0.05` |
| Тексты и эмбеддинги (LLM / RAG) | **Cosine / Euclidean distance** между центроидами + доля `OOV` | Рост расстояния до обучающего облака векторов |

## Формула PSI (Population Stability Index)

$$\text{PSI} = \sum_{i=1}^{B} \left( P_i - Q_i \right) \times \ln\left(\frac{P_i}{Q_i}\right)$$

где $Q_i$ — доля эталонной выборки (`reference`) в $i$-м квантильном
бине, а $P_i$ — доля текущей продакшен-выборки (`current`) в том же бине.

## Частые ловушки

| Симптом | Причина | Решение |
| :--- | :--- | :--- |
| `KS-test` звенит алертом каждый час на 100 000 запросов | На больших выборках $p\text{-value} \to 0$ даже при микроскопическом сдвиге на `0.1%` | Перейти с `p-value` на метрики размера эффекта: **PSI** или **Wasserstein distance** |
| Алерт сработал на дрейф неважного шумового признака | Мониторятся все 200 колонок с одинаковым весом | Фильтровать алерты по `Feature Importance` (топ-10 признаков) + **Prediction Drift** |
