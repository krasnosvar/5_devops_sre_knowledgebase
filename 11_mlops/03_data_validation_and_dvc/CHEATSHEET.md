## Когда что использовать для валидации данных

| Инструмент | Что проверяет | Скорость | Типичное место в архитектуре |
| :--- | :--- | :--- | :--- |
| **`Pydantic`** | Одиночный JSON / словарь / строка (`BaseModel`) | Микросекунды на 1 объект (ядро на Rust) | Валидация тела HTTP-запроса в `FastAPI` и структурированного ответа LLM |
| **`Pandera`** | Целые таблицы `pandas` / `polars` (`DataFrameSchema`) | Векторно (миллисекунды на 100 тыс. строк) | Проверка датасета в Python-скрипте перед обучением или чанкингом (`@pa.check_types`) |
| **`Great Expectations` (GX)** | SQL-таблицы (`PostgreSQL`, `ClickHouse`), `Spark`, `Parquet` | Секунды (тяжёлый фреймворк) | Корпоративные ETL-пайплайны в `Airflow` с автогенерацией HTML-отчётов (`Data Docs`) |
| ⚠️ Ловушка: прогон миллиона строк табличного датасета через `Pydantic` в цикле `for` | В 20–50 раз медленнее векторной проверки `Pandera` | Используйте `Pandera` для таблиц, а `Pydantic` — для API и конфигов |

## Основные измерения качества данных (Data Quality Dimensions)

| Метрика качества | Что означает | Пример нарушения в личном архиве документов |
| :--- | :--- | :--- |
| **Completeness** (Полнота) | Доля заполненных обязательных полей (`NOT NULL`) | Сканированный PDF без текстового слоя дал пустую строку `text = ""` |
| **Validity** (Валидность) | Соответствие формату, диапазону и списку значений | Категория `medcine` с опечаткой вместо `medicine`, дата `2099-15-40` |
| **Uniqueness** (Уникальность) | Отсутствие дубликатов по ключу или хэшу текста | Один и тот же анализ крови загружен трижды под разными именами файлов |
| **Consistency** (Непротиворечивость) | Логическая согласованность между полями | Дата выдачи справки раньше даты рождения или отрицательная сумма в чеке |

## Работа с `DVC` (Data Version Control) и локальным S3 (`SeaweedFS`)

| Задача | Команда |
| :--- | :--- |
| Инициализировать DVC в Git-репозитории | `dvc init` |
| Настроить локальный S3 (`SeaweedFS` на порту `8333`) как remote | `dvc remote add -d s3store s3://dvc-bucket` <br> `dvc remote modify s3store endpointurl http://localhost:8333` |
| Поставить большой файл/папку под контроль DVC (создаст `.dvc`-файл) | `dvc add data/raw_documents` (`git add data/raw_documents.dvc .gitignore`) |
| Отправить бинарные данные из локального кэша `.dvc/cache` в S3 | `dvc push` |
| Подтянуть нужную версию данных после `git checkout <tag>` | `dvc pull` |
| Запустить DAG-пайплайн (`dvc.yaml`) — пересчитает только изменившиеся шаги | `dvc repro` |
| Сравнить метрики текущего эксперимента с `HEAD` или другой веткой | `dvc metrics diff` |

> Проверка: `python3 02_examples/validate_docs_schema.py`; не проверено: `dvc push` (требует запущенного S3-сервера SeaweedFS).
