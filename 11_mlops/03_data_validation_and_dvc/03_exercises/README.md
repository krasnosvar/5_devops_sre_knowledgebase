# Упражнения — Качество, валидация и версионирование данных

Стенд: 🐳 Tier 1 — Локальный Python и DVC.

## Упражнение 1 — Проверка контракта данных и отлов Data Leakage

**Задача:**
1. Запустить валидатор `../02_examples/validate_docs_schema.py` и убедиться,
   что эталонный набор `golden_docs_dataset.json` проходит все проверки.
2. Скопировать `golden_docs_dataset.json` во временный файл `/tmp/test_docs.json`
   и добавить в него новую запись с `doc_id: "med_999"`, скопировав в неё
   поле `text` из `"med_001"` (но добавив пару лишних пробелов).
3. Проверить, перехватит ли функция `validate_dataset` нечёткий дубликат
   текста (защита от Data Leakage).

## Упражнение 2 — Расширение валидатора правилом Consistency

**Задача:**
Добавить в функцию `validate_dataset` правило логической непротиворечивости
(Consistency): дата документа `doc_date` не должна находиться в будущем
относительно сегодняшнего дня (`datetime.now().date()`), чтобы отлавливать
ошибки распознавания года при OCR (например, `2029` вместо `2026`).

## Упражнение 3 — Инициализация DVC во временном репозитории

**Задача:**
1. Создать временный Git-репозиторий в `/tmp/dvc_lab`, инициализировать в
   нём `DVC` (`uvx dvc init`).
2. Скопировать туда `golden_docs_dataset.json` и поставить его под контроль
   DVC (`uvx dvc add golden_docs_dataset.json`).
3. Посмотреть содержимое сгенерированного файла `golden_docs_dataset.json.dvc`
   и структуру каталога `.dvc/cache/files/md5/`, затем удалить `/tmp/dvc_lab`.
