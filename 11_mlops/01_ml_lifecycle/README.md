# 01. ML Lifecycle — жизненный цикл модели

## Зачем
Модель в продакшне — это не один файл, а цепочка: данные → обучение →
оценка → деплой → мониторинг → переобучение. Тема показывает этот цикл
целиком и где в нём работает DevOps/MLOps-инженер: хранилища, пайплайны,
serving, алерты на drift. Без этой карты остальные темы раздела выглядят
набором разрозненных инструментов.

## Как проходить
1. Прочитать теорию целиком, держа в голове схему «Полный цикл».
2. Для каждого этапа цикла назвать инструмент из своей практики, который
   отвечает за него в обычном DevOps, и найти его ML-аналог.
