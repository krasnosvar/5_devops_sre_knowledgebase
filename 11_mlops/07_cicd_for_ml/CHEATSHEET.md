## 4 уровня тестов в ML CI/CD

| Уровень | Что проверяем | Инструменты | Время в CI |
| :--- | :--- | :--- | :--- |
| **1. Код и фичи** | Чистые функции предобработки, отсутствие `NaN`, детерминизм при `seed=42` | `pytest`, `ruff`, `mypy` | `< 10 с` |
| **2. Данные (Data CI)** | Схема, диапазоны, отсутствие утечки целевой переменной и PII | `Pandera`, `Great Expectations`, `dvc status` | `10–30 с` |
| **3. Поведение модели** | `MFT` (явные кейсы), `INV` (инвариантность к шуму), `DIR` (направленность) | `pytest`, `promptfoo`, `deepeval` | `30–90 с` |
| **4. Инфраструктура + Gate** | Латентность `p95`, память, сравнение `@challenger` vs `@champion` на Golden Set | `onnxruntime`, `MLflow Client`, `locust` | `1–3 мин` |

## Три поведенческих теста модели (методология CheckList)

| Тип теста | Суть проверки | Пример для классификатора личных документов |
| :--- | :--- | :--- |
| **MFT (Minimum Functionality)** | Простые однозначные примеры, на которых модель **не имеет права** ошибаться | `"Гемоглобин 145 г/л, СОЭ 5 мм/ч"` $\rightarrow$ строго `medical` (`prob > 0.8`) |
| **INV (Invariance Test)** | Предсказание **не меняется** при незначимых возмущениях (регистр, пробелы, опечатка, замена ФИО) | Замена `"Иванов И.И."` на `"Петров П.П."` не меняет класс документа |
| **DIR (Directional Expectation)** | Предсказание **предсказуемо сдвигается** при направленном изменении входа | Добавление фразы `"КБК 18210102010011000110 ИНН"` повышает вероятность `government_tax` |

## Логика Quality Gate (условие промоушена в `@champion`)

Модель-кандидат (`@challenger`) получает алиас `@champion` только при
одновременном выполнении **всех** условий:
1. `F1_macro(challenger) >= F1_macro(champion) - 0.005` (нет общей
   деградации на Golden Dataset).
2. `Recall_medical(challenger) >= 0.95` (нет просадки на критичном
   срезе данных — Slice-based Evaluation).
3. `MFT_pass_rate == 1.0` (100% прохождение золотых правил).
4. `Latency_p95_cpu <= 10 ms` и `Model_size_MB <= 250 MB`.
