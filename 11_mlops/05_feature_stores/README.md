# 05. Feature Stores

## Зачем
Если признак «средний чек за 30 дней» при обучении считается одним
кодом, а в онлайне — другим, модель в продакшне видит не те данные, на
которых училась (training-serving skew). Feature store держит одно
определение признака и отдаёт его и для обучения (offline), и для
инференса с низкой latency (online). Тема объясняет архитектуру, Feast
и когда такая система оправдана, а когда избыточна.

## Пререквизиты
- [01_ml_lifecycle](../01_ml_lifecycle/) и

2. Для одного известного вам ML-сервиса ответить по разделу «Когда нужен
   Feature Store», оправдан ли он там.
