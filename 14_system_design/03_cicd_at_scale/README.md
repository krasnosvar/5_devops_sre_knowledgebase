# 03. CI/CD на масштабе

## Зачем

Пайплайн, удобный для одного сервиса, на сотнях сервисов и тысячах хостов
становится узким местом: долгие сборки, очереди раннеров, медленная и
рискованная раскатка. Тема о том, как строить CI/CD для флота: неизменяемые
артефакты, флот раннеров с кэшем, push vs pull конфигурация, волновая и
canary-раскатка, GitOps как ответ на масштаб.

## Как проходить

1. Прочитать теорию по порядку разделов.
2. Для знакомого пайплайна оценить: где он станет узким местом при
   росте числа сервисов в 10 раз.
3. Ответить на вопросы в конце файла.
