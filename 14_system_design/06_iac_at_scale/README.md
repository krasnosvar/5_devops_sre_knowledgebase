# 06. IaC на масштабе организации

> Уже знакомы с темой? → [CHEATSHEET.md](./CHEATSHEET.md) — команды и шаблоны
> одним экраном.

## Зачем

Когда инфраструктуру описывают десятки команд, проблемы уже не в
синтаксисе Terraform, а в организации: кто владеет каким state, как
команды переиспользуют модули без поломок, как не дать случайно
изменить чужие ресурсы и как ловить дрифт на тысячах ресурсов.

Без лабы: организационный масштаб не воспроизводится в учебном стенде на
несколько ресурсов.

## Как проходить

1. Прочитать теорию по порядку разделов.
2. Нарисовать для знакомой инфраструктуры разбиение state по владению и
   проверить, кто может сломать чужие ресурсы.
3. Ответить на вопросы в конце файла.
