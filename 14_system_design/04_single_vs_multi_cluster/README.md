# 04. Один кластер или много

> Уже знакомы с темой? → [CHEATSHEET.md](./CHEATSHEET.md) — команды и шаблоны
> одним экраном.

## Зачем

Рано или поздно встаёт вопрос: продолжать растить один Kubernetes-кластер
или делить на несколько. Тема даёт критерии решения — пределы control
plane и etcd, blast radius, паттерны деления (по окружению, региону,
тенанту, уровню критичности) — и инструменты управления флотом кластеров.

1. Прочитать теорию по порядку разделов.
2. Применить чеклист из раздела 6 к знакомой вам системе (рабочей или
   учебной) и записать вывод с обоснованием.
3. Ответить на вопросы в конце файла.
