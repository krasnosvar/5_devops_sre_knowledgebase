# 01. Масштабирование высоконагруженных систем

## Зачем

Когда нагрузка растёт, «добавить серверов» перестаёт работать: упираетесь
в базу, в соединения, в лимиты ОС. Тема учит выбирать стратегию
масштабирования — с Kubernetes (HPA/VPA/KEDA) и без него (флот VM,
immutable infrastructure) — и заранее видеть типичные узкие места
(connection storm, cache stampede, stateful-компоненты).

## Как проходить

1. Прочитать теорию по порядку разделов.
2. Для каждого узкого места из раздела 6 вспомнить, на каком уровне
   (приложение, ОС, кластер, база) оно проявляется и как его заметить в
   метриках.
3. Ответить на вопросы в конце файла, не подглядывая в ответы.
