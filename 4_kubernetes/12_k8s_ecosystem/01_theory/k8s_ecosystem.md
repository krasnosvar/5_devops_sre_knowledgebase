# Экосистема Kubernetes: дистрибутивы, инструменты, куда смотреть дальше

Это не теория с упражнениями, а справочная карта — что ещё существует вокруг
ванильного Kubernetes, помимо тем, разобранных в этом разделе.

## 1. Альтернативные дистрибутивы

- **OpenShift** (Red Hat) — enterprise-дистрибутив с встроенным CI/CD (Tekton), собственной абстракцией `Route` вместо голого Ingress, встроенным container registry. Строже security-дефолты "из коробки" (Security Context Constraints вместо Pod Security Admission).
- **Rancher / RKE2** — платформа для мультикластерного управления с собственным UI; популярна в on-premise и гибридных инсталляциях, где нужно централизованно администрировать десятки кластеров.
- **k3s** — CNCF-сертифицированный lightweight-дистрибутив (бинарник < 100MB), по умолчанию использует SQLite вместо etcd. Стандарт для edge/IoT и локальной разработки.
- **k0s / MicroK8s** — похожие по духу lightweight-варианты (Mirantis и Canonical соответственно), разные компромиссы по умолчанию (systemd-интеграция, snap-пакеты).

## 2. Инструменты для повседневной работы

- **k9s** — TUI (терминальный UI) для кластера: навигация по namespace/подам/логам без набора десятков `kubectl get/describe/logs` руками.
- **kubectx / kubens** — мгновенное переключение между кластерами (`kubectx`) и namespace (`kubens`) без правки `--context`/`-n` в каждой команде.
- **stern** (или `kubetail`) — tail логов сразу с нескольких подов, отобранных по label, с цветовой подсветкой источника.
- **kubectl-neat** — плагин kubectl, убирающий из `kubectl get -o yaml` весь автосгенерированный шум (managedFields, status, пустые поля) — то, что реально писал человек, читается за секунды.
- **Lens** — desktop GUI-IDE для кластера: графики ресурсов, редактирование манифестов, встроенный терминал в под.

## 3. Куда смотреть дальше

- [CNCF Landscape](https://landscape.cncf.io/) — интерактивная карта всей облачно-нативной экосистемы (сотни проектов по категориям).
- [kubernetes.io/docs](https://kubernetes.io/docs/) — официальная документация, первоисточник для любого спорного вопроса.
- [Kubernetes Enhancement Proposals (KEPs)](https://github.com/kubernetes/enhancements) — куда движется сам API (что стабилизируется, что депрекейтится).
- [awesome-kubernetes](https://github.com/ramitsurana/awesome-kubernetes) — курируемый список инструментов, статей и обучающих материалов.
