# Книги и ресурсы

## Книги

### SRE и надёжность
- **Site Reliability Engineering** (Google) — [бесплатно онлайн](https://sre.google/sre-book/table-of-contents/). Классика. Читать главы про SLO, toil, incident management.
- **The Site Reliability Workbook** (Google) — [бесплатно онлайн](https://sre.google/workbook/table-of-contents/). Практика из первой книги.
- **Accelerate** (Forsgren, Humble, Kim) — исследование что отличает высокоэффективные IT-команды. DORA метрики.
- **Release It!** (Nygard) — паттерны надёжности: circuit breaker, bulkhead, timeout. Практика.

### DevOps культура
- **The Phoenix Project** (Kim, Behr, Spafford) — роман о DevOps трансформации. Легко читается.
- **The DevOps Handbook** (Kim et al.) — практика из Phoenix Project. Конкретные паттерны.
- **Team Topologies** (Skelton, Pais) — как организовать команды для быстрой поставки.

### Kubernetes и инфраструктура
- **Kubernetes in Action** (Lukša) — лучшая книга по k8s для практиков.
- **Production Kubernetes** (Rosso et al.) — k8s в production: networking, storage, security.
- **Terraform: Up and Running** (Brikman) — Terraform от основ до production.

### MLOps
- **Designing Machine Learning Systems** (Chip Huyen) — ML в production: feature store, monitoring, деплой.
- **Practical MLOps** (Gift, Deza) — практика: MLflow, AWS SageMaker, pipelines.

## Курсы и практика

### Kubernetes
- [Killercoda](https://killercoda.com/) — **бесплатные** интерактивные лабы в браузере. CKA сценарии.
- [KodeKloud](https://kodekloud.com/) — практические курсы с лабами (CKA, CKAD, Terraform, GitOps). Частично бесплатно.
- [Linux Foundation CKA](https://training.linuxfoundation.org/certification/certified-kubernetes-administrator-cka/) — официальная сертификация.

### Terraform / IaC
- [HashiCorp Learn](https://developer.hashicorp.com/terraform/tutorials) — **бесплатные** официальные туториалы.
- [Terraform Associate](https://www.hashicorp.com/certification/terraform-associate) — сертификация начального уровня.

### AWS
- [AWS Skill Builder](https://skillbuilder.aws/) — **бесплатные** курсы от AWS.
- [AWS Solutions Architect Associate](https://aws.amazon.com/certification/certified-solutions-architect-associate/) — самая популярная AWS сертификация.
- [Adrian Cantrill](https://learn.cantrill.io/) — лучшие курсы для AWS SA, дорогие но качественные.

### Linux
- [Linux Foundation LFCS](https://training.linuxfoundation.org/certification/linux-foundation-certified-sysadmin-lfcs/) — Linux system administration.
