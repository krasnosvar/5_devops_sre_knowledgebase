# 01. Сертификации

## Зачем

Сертификация не заменяет опыт, но структурирует подготовку и помогает
пройти фильтр резюме. Тема помогает выбрать, какие сертификации брать
(Kubernetes, AWS, Terraform, Linux), в каком порядке и как готовиться к
практическим экзаменам вроде CKA.

  [4_kubernetes](../../4_kubernetes/) для CKA/CKAD/CKS,
  [7_compute_platforms/02_aws](../../7_compute_platforms/02_aws/) для AWS,
  [5_iac](../../5_iac/) для Terraform Associate,

## Файлы

- [01_theory/certifications.md](./01_theory/certifications.md) — обзор
  сертификаций по направлениям, план подготовки к CKA, полезные alias на
  экзамене, оценка ценности, площадки для практики.

Без лабы: справочная тема, практика — в разделах базы и на площадках из
списка.

## Как проходить

1. Прочитать обзор и выбрать сертификацию под текущую цель.
2. Проверить актуальные формат, цену и версию экзамена на официальной
   странице — они меняются.
3. Пройти соответствующие разделы базы, затем симуляторы экзамена.

## Когда двигаться дальше

  (AWS, Terraform) и почему это влияет на ценность.
- Составили план подготовки с датой экзамена.
