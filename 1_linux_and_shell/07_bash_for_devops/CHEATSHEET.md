## Каркас скрипта

```bash
#!/usr/bin/env bash
set -euo pipefail

tmp="$(mktemp -d)"
cleanup() { rm -rf -- "$tmp"; }
trap cleanup EXIT
trap 'echo "ошибка в строке $LINENO: $BASH_COMMAND" >&2' ERR

log() { printf '%s %s\n' "$(date -Is)" "$*" >&2; }
die() { log "ERROR: $*"; exit 1; }

: "${API_URL:?API_URL не задан}"          # обязательная переменная
[[ $# -ge 1 ]] || die "usage: $0 <env>"   # обязательный аргумент

exec 9>/var/lock/myjob.lock               # один экземпляр
flock -n 9 || die "уже запущен"

retry() {                                 # повтор с backoff
  local n=0
  until "$@"; do
    n=$((n + 1)); (( n >= 5 )) && return 1
    sleep $((2 ** n))
  done
}
retry curl -fsS "$API_URL/health" >/dev/null
```

## Strict mode

| Опция | Что делает | Ловушка |
| :--- | :--- | :--- |
| `set -e` | выход при ненулевом коде | ⚠️ не срабатывает внутри `if`, `&&`/`\|\|`, в функции, вызванной как `f \|\| true` |
| `set -u` | ошибка на **unset**-переменной | пустая строка `""` — не ошибка; дефолт: `"${VAR:-default}"` |
| `set -o pipefail` | код пайпа = последний ненулевой | без него `false \| true` → 0 |
| `set -x` | трассировка команд | ⚠️ печатает секреты в лог CI |

⚠️ `local x=$(cmd)` маскирует код `cmd` (вернётся код `local`) — пишите
`local x; x=$(cmd)`.

## Subshell: где теряются переменные

| Конструкция | Subshell? |
| :--- | :--- |
| `( cmd )` | да |
| `cmd1 \| cmd2` | да, каждая часть (кроме последней при `shopt -s lastpipe` без job control) |
| `$(cmd)` | да |
| `{ cmd; }` | нет |
| `while … done < file` / `< <(cmd)` | нет — счётчик сохранится |

```bash
count=0
while read -r line; do count=$((count + 1)); done < <(grep ERROR app.log)
echo "$count"
```

## Перенаправления и коды возврата

| Конструкция | Смысл |
| :--- | :--- |
| `> f 2>&1` / `&> f` | stdout и stderr в файл |
| `2>&1 \| tee -a log` | в лог и на экран |
| `> /dev/null 2>&1` | тишина |
| `<<'EOF'` | heredoc без подстановок (`<<EOF` — с подстановками) |
| `$?` | код последней команды (`0` — успех) |
| `${PIPESTATUS[@]}` | коды всех частей последнего пайпа |
| `cmd \|\| true` | ⚠️ осознанно игнорировать ошибку |

| Код | Смысл |
| :--- | :--- |
| `1` / `2` | общая ошибка / неверное использование |
| `126` / `127` | не исполняемый / не найден |
| `128+N` | убит сигналом N (`130` — Ctrl+C, `137` — SIGKILL) |

## Переменные и строки

| Задача | Синтаксис |
| :--- | :--- |
| Передать дочерним процессам | `export VAR=val` (только для одной команды: `VAR=val cmd`) |
| Дефолт / ошибка если пусто | `${VAR:-def}` / `${VAR:?msg}` |
| Длина | `${#s}` |
| Срезать суффикс / префикс | `${s%.gz}` `${s%%.*}` / `${s#*/}` `${s##*/}` |
| Замена | `${s/old/new}` (все: `${s//old/new}`) |
| Регистр | `${s^^}` / `${s,,}` |
| Массив | `arr=(a "b c")`; `"${arr[@]}"`; `${#arr[@]}` |
| Ассоциативный массив | `declare -A m=([k]=v)`; `"${!m[@]}"` — ключи |
| Строки файла в массив | `mapfile -t lines < file` |
| Арифметика | `$(( a + b ))`, `(( n > 5 ))` |
| Подстановка команды | `$(cmd)` (не обратные кавычки) |

⚠️ Всегда кавычьте: `"$var"`, `"$@"`. Без кавычек — word splitting и glob:
`rm -rf $DIR/` при пустом `DIR` бьёт по `/`.

## Тесты и циклы

| Задача | Синтаксис |
| :--- | :--- |
| Файл / каталог / непустой | `[[ -f f ]]`, `[[ -d d ]]`, `[[ -s f ]]` |
| Строка пустая / непустая | `[[ -z $s ]]` / `[[ -n $s ]]` |
| Regex | `[[ $s =~ ^v[0-9]+$ ]]` (группы: `${BASH_REMATCH[1]}`) |
| Команда существует | `command -v jq >/dev/null \|\| die "нужен jq"` |
| Перебор файлов | `for f in /var/log/*.log; do …; done` |
| Безопасно по именам с пробелами | `find . -name '*.log' -print0 \| xargs -0 gzip` |
| Параллельно | `xargs -P4 -n1 …` |

## Фон и сигналы

| Задача | Команда |
| :--- | :--- |
| Пережить закрытие SSH | `nohup cmd > out.log 2>&1 &` или `disown` |
| Лучше | `tmux`/`screen`, `systemd-run --user …` |
| Дождаться фоновых задач | `wait` (код конкретной: `wait $pid`) |
| Таймаут команды | `timeout 30 cmd` |
| Очистка при любом выходе | `trap cleanup EXIT` |

## Линтинг и отладка

| Задача | Команда |
| :--- | :--- |
| Только синтаксис | `bash -n script.sh` |
| Статический анализ | `shellcheck script.sh` |
| Трассировка | `bash -x script.sh` (или `set -x` … `set +x`) |
| Shebang проигнорирован | `sh script.sh` запускает `sh` (dash) ⚠️ bashisms упадут |

> Проверка: каркас прошёл `bash -n` и прогон (bash 5.3); поведение
> `set -u`, `pipefail`, пайпа/`lastpipe`/process substitution, `set -e` в
> `f || true`, `local x=$(false)`, раскрытий параметров, `mapfile`,
> `PIPESTATUS` проверено в `bash -c`; не проверено: `shellcheck` (не
> установлен).
