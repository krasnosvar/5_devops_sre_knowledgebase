# 12. Сравнение платформ

## Зачем
Итоговая тема раздела: собрать знания об облаке, bare metal и on-prem
виртуализации в одну модель выбора. Вопрос «где запускать» на практике
решается по стоимости при реальной нагрузке, задержкам, требованиям
compliance и возможностям команды, а не по моде.

## Пререквизиты
- Все предыдущие темы раздела, минимум
  [01_cloud_fundamentals](../01_cloud_fundamentals/),
  [05_baremetal_fundamentals](../05_baremetal_fundamentals/) и одна из
  [10_proxmox](../10_proxmox/) / [11_vmware_vsphere](../11_vmware_vsphere/).

## Файлы
- [01_theory/platform_comparison.md](./01_theory/platform_comparison.md) —
  матрица выбора, финансовая модель, сценарии (стартап, постоянная
  нагрузка, GPU, compliance, существующий vSphere), различия в
  производительности, итоговые рекомендации.

Без примеров и упражнений: тема аналитическая. Цифры в теории —
ориентировочные; для реального решения пересчитайте их по актуальным
прайсам.

## Как проходить
1. Прочитать теорию.
2. Взять реальный или выдуманный сервис (нагрузка, данные, требования) и
   пройти по матрице выбора, записав аргументы по каждой оси.
3. Посчитать стоимость вашего сценария в облаке и на bare metal на
   горизонте 3 лет.

## Когда двигаться дальше
- Можете обосновать выбор платформы для 2-3 разных сценариев.
- Можете объяснить, при какой загрузке облако перестаёт быть дешевле
  своего железа и почему.

Дальше — следующий раздел [8_observability](../../8_observability/).
