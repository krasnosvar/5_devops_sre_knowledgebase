# 05. Bare Metal — фундамент

## Зачем
Для GPU-инференса, высоконагруженных СУБД, HPC и задач с жёсткими
требованиями compliance виртуализация и облачная наценка мешают. Чтобы
выжать из физического сервера всё, нужно понимать его устройство: NUMA,
шину PCIe, SR-IOV, RDMA, типы дисков, питание и охлаждение. Тема
объясняет, когда bare metal оправдан и чем он отличается от VM.

## Файлы
- [01_theory/baremetal.md](./01_theory/baremetal.md) — когда выбирать bare
  metal, NUMA (`numactl`), PCIe и SR-IOV, RDMA, типы серверов, форм-факторы
  дисков и SMART, питание и управление частотой CPU.

Без отдельной лабы: большинство команд (`lscpu`, `numactl --hardware`,
`lspci`, `lsblk`) можно выполнить на любой Linux-машине или VM, но
NUMA, SR-IOV и RDMA по-настоящему видны только на серверном железе.

## Как проходить
1. Прочитать теорию.
2. Выполнить команды из теории на своей машине или VM из
   [0_lab_setup/02_local_vms](../../0_lab_setup/02_local_vms/) и сравнить
   вывод с описанием (на ноутбуке будет один NUMA-узел — это нормально).
3. Для каждого сценария из списка «Типичные применения» сформулировать,
   какое конкретно свойство железа даёт выигрыш.
