# 06. Out-of-Band Management

## Зачем
Сервер в стойке за сотни километров завис, или на нём ещё нет ОС — SSH
не поможет. BMC (iDRAC, iLO, XCC и другие) позволяет включить и
выключить сервер, увидеть консоль, выбрать загрузку по сети и прочитать
сенсоры независимо от ОС. Это основа любой автоматизации bare metal.

Без упражнений с ответами: для лабы нужен сервер с BMC (☁️ Tier 3 —
например, арендованный dedicated-сервер с доступом к IPMI/KVM).

## Как проходить
1. Прочитать теорию.
2. Прочитать `ipmi_toolkit.sh` и сопоставить каждую команду с разделом
   теории.
3. Если есть доступ к серверу с BMC: выполнить только читающие команды
   (`chassis power status`, `sdr`, `sel list`), затем попробовать SOL.
   Команды `power off/reset` — только на сервере, который можно
   перезагрузить.
