# Cloud Fundamentals

## Shared Responsibility Model

Что делает cloud provider, что делаете вы:

```
AWS отвечает за:                    Вы отвечаете за:
─────────────────                    ────────────────
Физическая безопасность ДЦ          Данные пользователей
Гипервизор и железо                 Шифрование данных
Сеть между дата-центрами            IAM политики и роли
Managed service internals           Сетевые группы безопасности (SG)
  (RDS патчи ОС, EKS control plane) Обновление ОС на EC2
                                     Конфигурация приложений
```

Чем выше уровень сервиса (IaaS→PaaS→SaaS), тем меньше ответственности у вас.

## Регионы и зоны доступности

**Region** — географическая локация. Независима от других регионов.
Примеры: eu-central-1 (Frankfurt), us-east-1 (N.Virginia), ap-southeast-1 (Singapore).

**Availability Zone (AZ)** — изолированный дата-центр внутри региона.
Минимум 3 AZ на регион. Соединены высокоскоростной частной сетью.
Отказ одной AZ не затрагивает другие.

**Правило высокой доступности:** размещать ресурсы минимум в 2 AZ.

```
eu-central-1 (Frankfurt)
├── eu-central-1a   ← ваши EC2 в этой AZ
├── eu-central-1b   ← ваши EC2 в этой AZ (HA)
└── eu-central-1c
```

## Модели сервисов

**IaaS (Infrastructure as a Service)** — EC2, VMs.
Вы управляете ОС, middleware, приложением. Максимальный контроль.

**PaaS (Platform as a Service)** — RDS, App Engine, Heroku.
Вы управляете приложением и данными. ОС и middleware — провайдер.

**SaaS (Software as a Service)** — Gmail, Salesforce.
Вы используете приложение. Всё остальное — провайдер.

**Serverless / FaaS** — Lambda, Cloud Functions.
Вы пишете функцию. Провайдер управляет всем инфраструктурным слоем.

## Billing модели

**On-Demand** — платишь за использованное время. Гибко, дорого.

**Reserved Instances / Savings Plans** — обязательство на 1-3 года. Скидка 30-70%.
- Reserved: фиксированный тип инстанса
- Savings Plans: гибко (любой EC2 в регионе/семействе)

**Spot Instances** — неиспользованные мощности AWS по аукциону. Скидка 60-90%.
Могут быть отозваны с 2-минутным предупреждением. Для stateless и batch workloads.

**Free Tier** — первые 12 месяцев или always-free:
- EC2 t2.micro: 750 ч/мес первые 12 мес
- S3: 5 GB always-free
- Lambda: 1 млн вызовов/мес always-free

## Сетевые концепции

**VPC (Virtual Private Cloud)** — изолированная виртуальная сеть в облаке.

**Public subnet** — есть маршрут через Internet Gateway. EC2 могут иметь публичный IP.

**Private subnet** — нет прямого доступа из интернета. Исходящий трафик через NAT Gateway.

**Security Group** — stateful L4 firewall для EC2/RDS. Разрешаете конкретные порты/протоколы/CIDR.

**NACL (Network ACL)** — stateless L4 firewall на уровне подсети. Нужно явно разрешить ответный трафик.

## Multi-AZ vs Multi-Region

**Multi-AZ** — защита от отказа одного дата-центра. RTO минуты. Стандарт для production.

**Multi-Region** — защита от отказа региона (редко, но бывает). RTO часы. Disaster Recovery.
Дорого и сложно. Нужно только при требованиях RPO/RTO это обосновывающих.

## CapEx vs OpEx

Традиционная инфраструктура: большие капитальные затраты (CapEx) — серверы, ДЦ.
Облако: операционные затраты (OpEx) — платишь по мере использования.

Преимущество облака: не замораживать капитал, масштабировать под реальную нагрузку.
Недостаток: при постоянной нагрузке 3+ лет — своё железо дешевле (bare metal).
