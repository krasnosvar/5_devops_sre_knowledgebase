## Shared Responsibility

| Слой | IaaS (EC2) | PaaS (RDS, EKS control plane) | SaaS |
| :--- | :--- | :--- | :--- |
| ДЦ, железо, гипервизор | провайдер | провайдер | провайдер |
| ОС и её патчи | **вы** | провайдер | провайдер |
| Сеть: SG / NACL / маршруты | **вы** | **вы** | провайдер |
| IAM-политики и роли | **вы** | **вы** | **вы** (пользователи) |
| Данные и их шифрование | **вы** | **вы** | **вы** |
| Конфигурация приложения | **вы** | **вы** | частично |

## Модели сервисов

| Модель | Примеры | Вы управляете | Когда |
| :--- | :--- | :--- | :--- |
| IaaS | EC2, Compute Engine, Azure VM | ОС, middleware, приложение | нужен полный контроль, legacy |
| PaaS | RDS, App Engine, Heroku | приложение и данные | стандартный стек, мало ops-людей |
| SaaS | Gmail, Salesforce | только использование | не ваша основная компетенция |
| FaaS / Serverless | Lambda, Cloud Functions | код функции | событийные, редкие, спайковые нагрузки |

## Регионы и AZ

| Понятие | Что это | Правило |
| :--- | :--- | :--- |
| Region | географическая локация (`eu-central-1`) | независим от других регионов |
| AZ | изолированный ДЦ внутри региона (`eu-central-1a`) | у новых регионов 3+ AZ |
| HA | ресурсы минимум в 2 AZ + LB | стандарт для production |
| Multi-AZ | защита от отказа ДЦ | RTO — минуты |
| Multi-Region | защита от отказа региона (DR) | RTO — часы, дорого; только под RPO/RTO |

| Задача | Команда (AWS CLI) |
| :--- | :--- |
| Список регионов | `aws ec2 describe-regions --query 'Regions[].RegionName' --output text` |
| AZ текущего региона | `aws ec2 describe-availability-zones --query 'AvailabilityZones[].ZoneName'` |
| Кто я (аккаунт / роль) | `aws sts get-caller-identity` |

## Модели оплаты

| Модель | Скидка | Обязательство | Для чего |
| :--- | :--- | :--- | :--- |
| On-Demand | 0 | нет | старт, непредсказуемая нагрузка |
| Reserved Instances | 30–70% | 1–3 года, фикс. тип | стабильная база |
| Savings Plans | 30–70% | 1–3 года, $/час | стабильная база, гибко по типам |
| Spot | 60–90% | нет | stateless, batch, CI, dev |
| Free Tier | — | — | лаба; условия зависят от даты аккаунта |

- ⚠️ Spot отзывается с предупреждением за 2 минуты; аукциона ставок
  больше нет — цена плавно меняется по спросу.
- ⚠️ Аккаунты после 15.07.2025 — кредитная модель Free Tier; сверяйтесь с
  https://aws.amazon.com/free/ перед лабой.
- ⚠️ Не входят в Free Tier: EKS control plane ($0.10/ч), NAT Gateway
  (почасово + за каждый GB) — главные источники счёта после лабы.

## Сеть: базовые понятия

| Элемент | Уровень | Состояние | Суть |
| :--- | :--- | :--- | :--- |
| VPC | регион | — | изолированная виртуальная сеть |
| Public subnet | AZ | — | маршрут `0.0.0.0/0 → IGW` |
| Private subnet | AZ | — | исходящий трафик через NAT Gateway |
| Security Group | ENI / инстанс | stateful | только allow-правила |
| NACL | подсеть | stateless | allow и deny, ответный трафик — явно |

## CapEx vs OpEx

| | CapEx (своё железо) | OpEx (облако) |
| :--- | :--- | :--- |
| Платёж | вперёд, крупно | по факту использования |
| Масштаб | недели (закупка) | минуты |
| Выгодно | постоянная нагрузка 3+ лет | переменная или новая нагрузка |

> Проверка: команды AWS CLI сверены с `aws <svc> <op> help`
> (aws-cli 2.37.0), без обращений к API; не проверено: цены и скидки
> (меняются, сверяйте с прайсом провайдера).
