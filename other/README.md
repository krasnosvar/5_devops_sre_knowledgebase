# Other — интервью, карьера, ресурсы

Справочный раздел: куда идти дальше, что читать, как готовиться к интервью.

## Темы

1. [01_devops_interview](./01_devops_interview/) — типовые вопросы на DevOps/SRE
   интервью: Linux (процессы, сеть, файловая система), k8s (debugging, networking,
   scheduling), IaC (state, модули), CI/CD (pipeline design); system design задачи
   с DevOps-угла (спроектируй CI/CD платформу, observability стек, DR стратегию).

2. [02_certifications](./02_certifications/) — практические сертификации:
   CKA (Certified Kubernetes Administrator), CKAD, CKS, AWS Solutions Architect,
   Terraform Associate, GitLab Professional; что реально проверяют, как готовиться.

3. [03_books_and_resources](./03_books_and_resources/) — проверенные ресурсы:
   книги (SRE Book, The Phoenix Project, Accelerate, Release It!), курсы
   (KodeKloud, A Cloud Guru, Linux Foundation), YouTube каналы, newsletters.

## Как использовать

Открывать по необходимости: перед интервью, при выборе следующего направления
для изучения, при подготовке к сертификации.
